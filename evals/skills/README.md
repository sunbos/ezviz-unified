# 技能包评审材料

本目录收录技能包行为评审所用的合成案例与人工判定标准，供复跑与后续评审使用。

## 文件

- `cases.json`：7 个合成计划案例，按技能包分组；场景为虚构，期望产出是计划而非实际执行。
- `expectations.json`：逐案例的人工语义审查标准，供评审人核对输出；它不是自动评分器，也不得作为输入提供给被评审模型。

## 手动重跑

本评审没有自动运行命令，按下列步骤手动执行：

1. 开启一个独立的新会话，只提供目标技能包文本、选中的案例与要求的输出格式；不要提供 `expectations.json`。
2. 要求模型按案例返回结构化计划，字段为 `case_id`、`next_steps`、`conclusion`、`public_report`、`limitations`。
3. 收集全部输出后，由评审人逐条对照 `expectations.json` 人工核对，并记录结论与观察。
4. 如实记录复用情况：输入隔离不等于盲测，若案例曾参与技能包迭代，结论说明中应注明。

## 判定口径

- 结论属于人工语义判断；对外表述应为"人工核对覆盖核心标准"，不得写成执行成功率或自动通过率。
