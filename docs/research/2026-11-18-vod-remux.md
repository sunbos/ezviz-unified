# 云点播转封装任务与录像地址说明（VOD-REMUX-001）

本文说明 `client.vod` / `AsyncClient.vod` 上四个**仅国内**入口的公开调用形状、参数规则与边界：`create_remux_task`（doc 3971）、`task`（doc 3972）、`tasks`（doc 4941）、`recording_urls`（doc 3973）。冻结契约与分工见[实施计划](../plans/2026-11-18-vod-remux.md)与已登记准入 `docs/coordination/SP169/admission.json`（G1：`admit_bounded_offline_sdk_implementation_only`，基线 main `254ea73`）；本文是使用说明，不是实现完成或验收证据。

## 最小只读示例（同步）

`task` 与 `tasks` 是官方明确只读的查询。以下示例显式使用调用方自己的本地环境变量配置，不打印 token、设备标识、任务 ID、URL 或原始响应：

```python
import os
from ezviz_unified import Client, RegionConfig

with Client(
    os.environ["EZVIZ_APP_KEY"],
    os.environ["EZVIZ_APP_SECRET"],
    region=RegionConfig.china(),
) as client:
    # 单任务查询：task_id 由调用方显式提供，SDK 不枚举任务、不推断状态含义。
    response = client.vod.task("<taskId>")

    # 任务分页列表：task_type 仅接受 int 7 或 8；下面只取一页，不自动翻页。
    page = client.vod.tasks(7, page_start=0, page_size=10)
    total = page.data.get("total") if isinstance(page.data, dict) else None
```

## 最小只读示例（异步）

以下示例可作为普通 Python 文件运行。`"<taskId>"` 是占位符：运行前需调用方显式替换为自己有权查询的现成任务 ID，SDK 不自动创建或枚举任务；示例不打印 token、设备标识、任务 ID、URL 或原始响应：

```python
import asyncio
import os
from ezviz_unified import AsyncClient, RegionConfig


async def main() -> None:
    async with AsyncClient(
        os.environ["EZVIZ_APP_KEY"],
        os.environ["EZVIZ_APP_SECRET"],
        region=RegionConfig.china(),
    ) as client:
        response = await client.vod.task("<taskId>")
        page = await client.vod.tasks(8, page_start=0, page_size=10)


asyncio.run(main())
```

两个查询接口只复用既有的一次 invalid-token 恢复（provider 可刷新时）；没有一般网络重试、轮询或自动翻页。

## `create_remux_task`（doc 3971）

官方明确为**非幂等的异步任务创建**：`POST /api/service/open/vod/media/trans/code`。官方权限前提为企业用户、已有对应时段云录像、不支持托管/子账号；SDK 只做地区前置拒绝，不由 token provider 猜身份、不自动探测加密、不创建录像或开通套餐。

显式调用形状：

```python
response = client.vod.create_remux_task(
    "<deviceSerial>",
    local_index="<localIndex>",
    bus_type="1",                # 仅 "1"/"7"/"71" 三个字符串
    start_time=start,            # 整秒 naive datetime，编码 yyyy-MM-dd HH:mm:ss
    end_time=end,                # 10 <= end-start <= 172800 秒（48h），含端点
    format="MP4",                # 可选 "HLS"/"MP4"；None 省略且不注入默认
    space_id=None,               # bus_type="7" 时必填；None 省略
    result_space_id=None,        # 可选；None 省略，不互相填充
    validate_code=None,          # 可选；加密前提由调用方满足，SDK 不探测
    acceleration=None,           # 可选 int 非 bool 且 0/1；None 省略，不注入 0
)
```

- `device_serial` 与 `local_index` 以 **Header**（`deviceSerial`/`localIndex`，均为 String）发送；`accessToken` 由客户端 token provider 注入 Header，facade 不提供 token 参数。Header 字符串校验为 SDK 安全选择：str 非空白、ASCII、拒控制字符/DEL 与首尾空格、保留中间普通空格、不 strip、不做数值推断；`local_index` 无默认、不限定整数或正数。
- `bus_type` 是严格 str；`bus_type="7"` 且 `space_id=None` 前置拒绝，其它 bus_type 显式 `space_id` 仍发送；`bus_type="71"` 且显式 `format="HLS"` 前置拒绝，但 `format=None` 允许省略。`space_id`/`result_space_id` 为 int 非 bool，0/负数不由 SDK 凭空拒绝。
- `validate_code` 为 None 省略，否则非空白且 UTF-8 可编码的 str 原样发送；是否处于加密状态由调用方判断。
- 该方法只返回 `ApiResponse`，**不**变成任务句柄；作为非幂等写请求，10002/HTTP/服务端错误/timeout/断连均不自动重放——超时可能已有任务，结果未知需调用方显式再查。
- 费用/配额/高速扣量、去重键、任务保留期、时区、`spaceId` 与旧/统一空间的确切映射、`busType` 1/7 的默认 format、加密判定协议与错误信封映射均为保留未知项。

## `recording_urls`（doc 3973）

按设备、通道与时段签发录像地址：`POST /api/service/open/vod/file/address/hls`。官方前提为已有 accessToken、设备开通云存储且对应时段有录像、不支持托管/子账号；本页无企业等级要求，SDK 不复制 3971 的企业前提。

显式调用形状：

```python
response = client.vod.recording_urls(
    "<deviceSerial>",
    local_index="<localIndex>",
    start_time=start,            # 整秒 naive datetime；允许与 end 相等是 SDK 透明传递选择
                                 # （原文未给最小间隔），非官方承诺零时长请求必成功
    end_time=end,                # 0 <= end-start <= 172800 秒；不套 3971 的 10 秒下限，
                                 # 零时长行为以服务端实际校验为准
    format="MP4",                # 必填 "MP4"/"HLS"，无默认
    expire_seconds=None,         # 可选 int 非 bool，1..604800 含端点；None 省略，
                                 # 服务端默认 1800；SDK 不注入，也不套其它接口的下限
    space_id=None,               # 可选 int 非 bool；None 省略，默认空间交服务端
)
```

- `device_serial`/`local_index` 与 token 同样位于 Header，校验规则同 `create_remux_task`，`local_index` 无默认。
- 响应 `data[]` 原样保留 `hlsAddress`/`stopTime`/`expireTime` 字段名；`format="MP4"` 也不造 `mp4Address` 别名，不转换 `expireTime` 的格式、时区或单位（均为未知项）。地址返回不证明媒体可播。
- `Operation.read_only=False` 在这里是 **SDK 设计选择**，仅禁用自动重放：来源称同参幂等但未明确无副作用（地址签发可能产生服务端记录），因此 10002/HTTP/API 错误/timeout/断连均不自动重放；这不是官方已明确写/非幂等的结论。调用方可显式再次调用，功能范围不缩减。

## 任务查询（doc 3972 / 4941）

- `task(task_id)`：`GET /api/service/open/vod/task`，query `taskId`。`task_id` 仅要求非空白 UTF-8 str 原样编码，不发明长度/正则/数值范围。响应保留 `taskType=1`、`taskSubType` 80/81/82、`taskStatus`、`progressRate` 原值：SDK 不猜测 `taskStatus` 各值的完成含义、不把 4941 的状态表复制为 3972 的事实，也不假定 `progressRate` 是 0..100 百分比；响应没有产物 node 或 URL 的合同。
- `tasks(task_type, ...)`：`GET /api/service/open/vod/tasks`，query `taskType` 必填，仅接受 int 非 bool 的 7/8——不能传 `create_remux_task` 的 `bus_type` 字符串或 3972 内部的 `taskType=1`。`page_start`/`page_size` 为 None 省略（服务端默认 0/10），显式时仅 int 非 bool、不附加未声明上下界；`start_time`/`end_time` 是 **opaque str**，为 None 各自省略、不要求成对，原样传送——格式与范围未由来源明确，SDK 不解析、不比较顺序、不套其它接口的 datetime 编码或时段限制。响应 `data.result[]` 与 `pageStart`/`pageSize`/`total` 原样返回，SDK 不自动翻页。

`recording_urls` 允许 `start_time` 与 `end_time` 相等同样是 SDK 透明传递选择：doc 3973 原文未声明最小间隔，故 SDK 前置校验不发明下限（也不套用 `create_remux_task` 的 10 秒下限）；这**不是**官方承诺所有零时长请求都会被服务端接受，实际可用性以服务端校验与对应时段是否有录像为准。

三个接口的任务状态编码体系互不相同（创建用 `busType` 1/7/71、单任务 `taskType=1`+`taskSubType` 80/81/82、列表 `taskType` 7/8），SDK 不归一；`taskId`、`fileNodeId` 与地址 URL 之间没有已审映射，不发明对应关系。剪辑任务产物查询（doc 3717，已审来源 hash `0e9e8875…8e3`）属于另一身份边界，本批不新增该操作、不推断 `taskId` 到 `fileNodeId` 的绑定。

## 通用边界

- 四者仅国内；区域守卫先于参数验证执行。全部返回 `ApiResponse`，`.data` 与 `.raw` 保留官方字段；不新增 facade、DTO、轮询、分页抓取或媒体下载，示例中的任务创建、地址签发与媒体获取均需调用方显式发起，SDK 不自动串联任务→媒体。
- `taskId` 与 `resultSpaceId` 已加入既有脱敏键集合；返回的地址 URL 只出现在 `data`/`raw` 中，不进入自动日志或诊断。
