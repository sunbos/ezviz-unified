# 图像参数契约与限制

原有图像参数接口依据 2026-11-14 归档的国内文档 3678–3689。后续使用 2026-11-17 冻结资料补入显示预设与两项 PUT 设置，并核实 3678、3680 的正文与已有读取契约一致。[原始来源审查](../validation/reviews/S011A/contracts-review.json) · [本批冻结记录](../coordination/domestic-image-configuration/admission.json)

`client.imaging`及异步同名入口返回`ApiResponse`。六项查询使用`get(device_serial, ImageSetting.<名称>)`，保留官方data字段与原始响应。

| ImageSetting | 查询文档 | 设置入口及范围 |
| --- | --- | --- |
| IMAGE_PARAMS | [3678](https://open.ys7.com/help/3678) | `set_image_params`，饱和度写入采用请求示例的 `saturation` |
| WHITE_BALANCE | [3680](https://open.ys7.com/help/3680) | `set_white_balance`，手动写入采用请求示例的 `manual` |
| BACKLIGHT | [3682](https://open.ys7.com/help/3682) | `set_backlight(serial, mode)`：close/up/down/left/right/center |
| DENOISING | [3684](https://open.ys7.com/help/3684) | `set_denoising(serial, mode, ...)`：close/general/advanced |
| EXPOSURE | [3686](https://open.ys7.com/help/3686) | `set_exposure(serial, microseconds)`：整数1–40000微秒 |
| ANTI_FLICKER | [3688](https://open.ys7.com/help/3688) | `set_anti_flicker(serial, mode)`：50Hz/60Hz |

降噪general模式必须提供`general_level`；advanced模式必须提供`spatial_level`和`temporal_level`。所有传入等级均为整数1–100，bool不视为整数。None省略；其他模式下显式提供的有效字段不会被SDK悄悄删除。数值范围来自相邻的设置页3683/3685/3687/3689。

GET的deviceSerial在query；PUT的deviceSerial与设置字段在form；两者accessToken均在Header。成功判断为整数`meta.code=200`；`meta.message`为消息，data原样返回，setter无data时为None。GET可以按客户端规则刷新过期token并重试一次，PUT不自动重放。

上表 3678–3689 系列要求设备能力 `support_image_param`；查询需要设备级GET权限，设置需要Config权限，官方说明支持托管/子账号。SDK不自动探测能力或提升权限，也不增加文档未声明的通道号或序列号大写限制。

## 显示预设

显示预设使用独立的 `get_display_mode(device_serial)` 和 `set_display_mode(device_serial, mode)`。同步和异步签名相同。读写两端将令牌与设备序列号放在请求头中，序列号须为可表示为 HTTP 头值的 ASCII 文本。SDK 拒绝控制字符与首尾空白，保留大小写。两个接口均按顶层字符串 `code="200"` 判定成功。[查询（1736）](https://open.ys7.com/help/1736) · [设置（1735）](https://open.ys7.com/help/1735)

写入只接受字符串 `"1"`、`"2"`、`"3"`，分别表示标准、写实和艳丽。读接口把 `data.valueInfo.mode` 描述为字符串，示例却返回整数。SDK 保留实际类型及额外字段。1735、1736 未给出最低子账号权限或特定能力位。这套预设和下文的 `image_style` 分别使用各自协议。

## 详细图像参数与白平衡

| 方法 | 必填参数 | 手动模式的附加参数 |
| --- | --- | --- |
| `set_image_params(device_serial, *, image_style, gamma_correction, gain, …)` | `image_style` 取 `standard`、`soft`、`gorgeous` 或 `manual`，`gamma_correction` 为 0–9，`gain` 为 0–100 | `brightness`、`contrast`、`saturation`、`sharpness` 四项均须提供，范围均为 0–100 |
| `set_white_balance(device_serial, mode, *, red=None, blue=None)` | `mode` 取 `auto`、`lock` 或 `manual` | `red`、`blue` 均须提供，范围均为 0–255，分别发送为 `whiteBalanceRed` 与 `whiteBalanceBlue` |

数值字段均要求整数，拒绝布尔值。非手动模式下，SDK 仍发送显式提供且通过校验的字段，`None` 表示省略。白平衡文档只承诺红、蓝增益在手动模式下生效。

- 饱和度在 3679 的表中写作 `saturatio`，PUT 示例发送 `saturation`。SDK 按 PUT 示例写入，3678 查询结果保留其原始键。[图像参数设置（3679）](https://open.ys7.com/help/3679)
- 白平衡字段表写作 `manul`，3681 的 PUT 示例发送 `manual`。SDK 手动写入只发送 `manual`，3680 返回的枚举原文可在响应中读取。[白平衡设置（3681）](https://open.ys7.com/help/3681)

这两个拼写选择已通过模拟传输验证，平台与具体设备是否接受仍待实测。写入失败后 SDK 不会换拼写或自动重发。真实写入需单独授权，事前核对目标设备的原值和恢复方法，特别是原配置为手动模式时。读取到配置值不能单独证明硬件画面效果。[来源差异登记](../../contracts/source-issues.json)

## 只读示例

在本机配置 `EZVIZ_REGION=domestic`、`EZVIZ_APP_KEY`、`EZVIZ_APP_SECRET` 及 `EZVIZ_DEVICE_SERIAL`。从仓库运行以下命令，只查询一次显示预设：

```bash
python -m examples.image_configuration --mode async --setting display
```

`--setting image` 与 `--setting white-balance` 分别使用已有图像参数和白平衡读取。示例只输出地区、模式、查询选项和状态。
