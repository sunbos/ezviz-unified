# S021消息助手验收

S021A生成纯函数实现与说明，S021B独立生成测试；两者只共享接口约定和公开协议资料，测试方未接收实现。均固定devin/swe-2、effort=max、零工具，新仓库可直接执行纯文本任务，无旧utils工作目录依赖。

签名使用标准库HMAC-SHA1、原始UTF-8正文与原样timestamp，digest字节用compare_digest比较；不从Client取AppSecret。解析保留未知字段、body类型与payload字符串，ACK仅返回新的messageId字典。缺向量、时间戳单位和重试资料差异继续保留。

协调方澄清了超限异常语义，未用宽泛异常断言掩盖差异；另外复现大整数JSON漏出底层ValueError，并要求转换为固定ProtocolError。拒绝依赖英文异常文案来分类，保留异常链不携带原文的处理。文档纠正“签名证明当前发送者持钥”的过度结论，明确重放旧报文也可能通过。

独立110项消息测试通过，涵盖RFC2202固定向量、OpenSSL交叉核对的UTF-8合成向量、错误签名与解析顺序、边界、类型保留、异常及repr。没有使用真实密钥、设备或回调消息，不能据离线向量声明平台端到端验签已通过。
