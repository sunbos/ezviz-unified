# Alpha集中审查结论

冻结审查起点为 `37722aeb4a785ae575a22f5f381f041f6637a278`。三个独立Claude会话分别审查认证/传输、存储/云录制、发行/维护证据；请求均为devin/swe-2、effort=max、零工具。审查者只做静态阅读，未把意见视为已执行的复现或全库质量保证。

## 逐项处置

| 发现 | 主导方结论 | 处置 |
| --- | --- | --- |
| Q001A-1 provider形态校验 | 部分采纳；已复现异步invalidate被丢弃并产生RuntimeWarning | 构造时拒绝明确的coroutine invalidate；首次get_token检查返回对象是否awaitable。拒绝强制async def getter的建议，保留普通def返回Future的合法协议 |
| Q001A-2 超大timeout | 采纳；四种Client/Transport均复现OverflowError | 仅转换浮点溢出为固定ValueError，不吞其他编程错误 |
| Q001A-3 日志覆盖边界 | 未确认真实httpcore秘密泄漏；只确认filter作用于httpx logger | 文档明确范围，不新增全局日志钩子，不声称能控制应用自行记录的原始响应 |
| Q001B-01 即时计划空数组 | 不采纳为缺陷 | 字段必填不等于数组必须非空；2062没有最小数量证据，不能宣称服务器必然拒绝。保留原来不猜计数范围的选择及未实测边界 |
| Q001C-1 发行物越界条目 | 采纳；已用构造归档复现 | 明确允许布局，拒绝未知顶层/源包及目录命名空间被普通文件占据 |
| Q001C-2 缺少源码包测试 | 采纳 | 必须包含conftest、离线策略和至少一份SDK测试；这不是执行测试或完整内容扫描 |
| Q001C-3 MANIFEST深度不一致 | 采纳 | 改为扁平SDK测试include，实际构建验证嵌套探针被排除，37个应包含文件均保留 |

## 修补与证据

Q002A与Q002B由Claude并行生成修补和回归，Codex核对、应用并执行验证。首次发行边界回归暴露18项失败；随后核心配置与目录类型回归在修补前暴露11项失败。修补后191项定向检查、全部2281项测试与11个子测试通过，mypy检查34个SDK文件通过，Ruff及110文件格式通过。

全部177项契约、1448次离线传输执行通过。wheel/sdist构建、元数据和干净安装通过；源码包实际执行1853项SDK测试。构建与安装receipt见[验证记录](../Q002B/validation.json)。没有新增真实萤石API调用。

一轮Q002A纯文本修订产生2次工具调用尝试，被执行约束拒绝，未采用输出；当时核心源码哈希确认未变。收窄为纯文本转换后，新的零工具结果通过审查。没有切换模型或放宽该约束。移除了候选中依赖sys.modules遍历任意Operation的多余测试，沿用既有确定性重试回归。

## 结论边界

本次已审查范围内，确认的问题已修补；远端四版本检查以最终提交的PR checks为准。该结论支持进入有明确限制的Alpha验收，不表示所有官方接口、所有设备/地区、自动修复或无人维护已经完成。候选方案仍需按来源、独立测试和真实验证分别评估。
