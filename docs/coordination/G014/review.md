# 海外设置、公开请求与 skills 验收

## 实现与审查

Claude Code 经 Magpie 使用 `devin/swe-2`、`max` 生成实现、测试、契约与说明；Codex 核对协议、审查差异并统一集成。后续测试执行也交给 Claude 的受限 Bash 会话，验收依据保存的工具原始输出，不依赖模型自报。

本批新增十项海外 Settings 调用及显式匿名模式。公开操作跳过认证 provider、token 注入与认证重试，必须配置明确的业务区域地址；原有认证初始化与生命周期规则保留。`timeFormat` 的官方必填性未说明，登记为有说明的 `required: null`，SDK 显式传参要求单独记录。

审查修正了测试中的错误构造参数、反射静态 Operation 的假设、宽泛异常捕获、无效取消测试、测试夹具仍为公开请求执行认证、文档域名与参数名错误，并移除了将字符串 `0`/`1` 误判为类型矛盾的来源问题。最终独立静态差异审查没有提出确定的 P1/P2 问题；该结论不替代运行验证。

## 验证证据

- 全量离线测试：3338 项与 11 项 subtests 通过。
- 已登记契约：196 条（国内130、海外66），1600 次离线传输执行通过；关联146篇来源文档，保留76条来源问题。
- 公开操作评测先复现两个预期失败，修订后5项集成/变异测试通过；原有整JSON请求体夹具修正后72项测试通过。
- SDK的38个源文件通过mypy；Ruff检查与144个纳入文件的格式检查通过。
- wheel与sdist构建、归档边界和Twine元数据检查通过；两种发行物均通过干净环境安装及同步/异步MockTransport smoke，sdist内2263项SDK测试通过。安装依赖阶段可联网，未用该检查调用真实业务API。
- 非隔离构建因本地缺少setuptools失败后，使用与CI一致的隔离构建完成；没有为此修改SDK运行依赖。
- 新加坡公开时区目录有无凭据HTTP及同步/异步SDK实测，均返回105项时区；[记录](../../validation/live/2026-11-15-public-timezones/singapore.json)绑定实际SDK文件哈希。
- 三份skills通过格式检查，7个合成计划案例经人工审查；实际维护命令只做同快照自比较。范围与迭代局限见[skills验证说明](../../validation/skills/2026-11-15/README.md)。

## 范围限制

九项设备端点未在海外真实设备上验证，未执行设备写入。公开目录的单区域成功不代表其他地区或型号均可用；候选路径出现次数不代表接口总数或支持率。[缺口分组](../../validation/2026-11-15-endpoint-gap-cohorts.json)保留本批扩展前的输入哈希与统计口径。
