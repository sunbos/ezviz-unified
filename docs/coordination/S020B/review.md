# S020B 源契约验收

五页原文2045、2046、2049、2050、2062均先核对原始归档SHA256与html_content SHA256，模型只接收明确筛选的文本及源身份。Codex确认五项method/path、Header token、三项JSON/两项表单、前四meta整数成功码与即时顶层字符串成功码。

嵌套设备字段作为devIndexInfos的约束保留，不伪装成独立顶层参数。源默认值保留在约束中，SDK的None省略不代表注入默认值。源未声明的时区、即时字段/数量与套餐上限、更新endTime条件及表单Boolean编码推导单独记录；本地hours正整数等校验不声称来自官方。

复核删除假冲突并修正data可缺失路径；即时案例不发送未经文档声明的validateCode。最终5项契约、绑定及独立wire案例进入登记，6项来源限制保留。原文缺参数不能按同系列接口自动补成支持。

实现/测试验收见[S020A记录](../S020A/review.md)。本任务未运行任何真实写操作。
