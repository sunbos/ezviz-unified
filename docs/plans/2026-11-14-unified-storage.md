# 统一存储实施计划

官网1975把云录制专用建空间入口标为旧版，推荐5236统一存储。按已批准的独立SDK路线，本批优先补齐统一存储引擎的七项API，云录制计划管理继续留在后续范围。

## 边界与分工

Claude Code固定devin/swe-2、effort=max，分别生成纯参数模型S019A、同步/异步facade S019B与来源复核S019C。Codex写独立回归、核对原文、应用候选并验证。所有新操作仅在离线模拟中执行。

统一存储导航中的5341实际为云录制1.0解冻，5342实际为云点播元数据；不把它们混成同一fileNodeId协议。新入口为Client.storage，普通SDK不增加LLM或维护服务依赖。
