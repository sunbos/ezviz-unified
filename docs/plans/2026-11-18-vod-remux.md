## 3. 公共签名（冻结）

同步与异步仅 `async` 差异，全部返回 `ApiResponse`：

```python
def create_remux_task(device_serial: str, *, local_index: str,
    bus_type: Literal["1", "7", "71"], start_time: datetime, end_time: datetime,
    format: Literal["HLS", "MP4"] | None = None,
    space_id: int | None = None, result_space_id: int | None = None,
    validate_code: str | None = None,
    acceleration: Literal[0, 1] | None = None) -> ApiResponse

def task(task_id: str) -> ApiResponse

def tasks(task_type: Literal[7, 8], *, page_start: int | None = None,
    page_size: int | None = None, start_time: str | None = None,
    end_time: str | None = None) -> ApiResponse

def recording_urls(device_serial: str, *, local_index: str,
    start_time: datetime, end_time: datetime, format: Literal["MP4", "HLS"],
    expire_seconds: int | None = None, space_id: int | None = None) -> ApiResponse
```

`acceleration` 注解为 `Literal[0, 1]` 但运行时仍按 int 非 bool 校验；`create_remux_task` 仅返回 `ApiResponse`，**不**变成 TaskHandle。

## 5. 参数与验证规则

**Header 字符串规则（SDK 安全选择，非官方事实）**：`device_serial`/`local_index` 必填 str，非空白、ASCII、拒控制字符/DEL 与首尾空格，保留中间普通空格，不 strip、不做数值推断；`local_index` 无默认、不限定整数/正数。

### 5.1 `create_remux_task`（3971）
- `bus_type`：严格 str 且仅 `"1"/"7"/"71"`，Literal 之外仍有运行时校验。
- `start_time`/`end_time`：整秒 naive datetime，编码 `yyyy-MM-dd HH:mm:ss`；`10 <= end-start <= 172800` 秒含端点；不默认时区、不静默转换。
- `bus_type="7"` 且 `space_id=None` → 前置拒绝；其它 bus_type 显式 `space_id` 仍发送，不人为丢弃。
- `bus_type="71"` 且显式 `format="HLS"` → 前置拒绝；`format=None` 允许且省略，不注入 `MP4`；`"1"/"7"` 省略 format 时服务端默认 unknown，保留未知。
- `space_id`/`result_space_id`：分别 int 非 bool；0/负数不由 SDK 凭空拒绝；None 各自省略、不相互填充。
- `validate_code`：None 省略；否则非空白 UTF-8 str 原样发送；加密前提由调用方满足，SDK 不探测、不总是强制。
- `acceleration`：None 省略；显式 int 非 bool 且 0/1；不注入官方默认 0。

### 5.2 `task`（3972）
- `task_id`：非空白 UTF-8 str 原样 query 编码；不发明长度/正则/数值范围。

### 5.3 `tasks`（4941）
- `task_type`：严格 int 非 bool 且 7/8；**不能**传 create 的 `bus_type` 或 3972 内部 `taskType=1`。
- `page_start`/`page_size`：None 省略；否则 int 非 bool，不附加未声明上下界，不强行发出默认 0/10。
- `start_time`/`end_time`：None 各自省略；否则非空白 UTF-8 str 原样传送；不要求成对、不比较字符串顺序、不套 48h/30d 或其他接口的 datetime 编码。

### 5.4 `recording_urls`（3973）
- Header 规则同 3971，`local_index` 无默认。
- `start_time`/`end_time`：整秒 naive datetime，拒 aware/microsecond 与逆序；**允许相等**（本页无最小间隔），跨度 `<=172800` 秒（48h）；不抄 3971 的 10 秒下限。
- `format`：必填 `MP4/HLS`，无默认。
- `expire_seconds`：None 省略（默认 1800 交服务端）；显式 int 非 bool 且 `1..604800` 含端点；不注入 1800，不套 1.0 的 60 秒或统一存储 30 秒下限。
- `space_id`：None 省略由服务端处理默认空间；显式 int 非 bool，无正数假设；不查找/构造默认空间。

## 6. 响应与状态编码

- 四者统一既有 `ResponsePolicy`：`meta.code` 整数、`success_values=(200,)`、`meta.message` 可缺、`data` 原样返回 `ApiResponse`。
- `task`：保留 `taskType=1`/`taskSubType` 80/81/82/`taskStatus`/`progressRate` 原值，不归一、不强制字段完整。
- `tasks`：`data.result[] + pageStart/pageSize/total`（不是 `data[]`/`lastId`/`hasNext`）；`taskType` 7/8、`taskStatus` 原值；不自动分页。
- `recording_urls`：`data[]` 保留 `hlsAddress`/`stopTime`/`expireTime` 字段名；`format=MP4` 也不造 `mp4Address`，不转换 `expireTime`。
- SDK 不做自动编排：不轮询任务、不推进分页、不下载媒体、不链式调用。

## 8. 保留未知项（不猜）

- 3971：费用/配额/高速转封装扣量、去重/idempotency key、任务保留期；时间时区；`spaceId` 与旧/统一空间确切映射；`busType` 1/7 默认 format；加密状态判定协议；错误信封/HTTP 层映射。
- 3972：`taskStatus` 完成值不能从 4941 复制；`progressRate` 不假定 0..100；响应无产物 node/URL 合同；本页未给额外账号/套餐范围。
- 4941：单侧时间筛选行为未确认——SDK 透明传送是本地选择，不承诺服务端支持任意组合；`progressRate` 虽称百分比但无强制范围，响应不做范围校验；分页上下限、排序稳定性、`total` 语义未知。
- 3973：`expireTime` 格式/时区/单位；字段必填/nullable/排序/分段规则；来源未明示转封装任务完成是必填前提；地址返回不证明媒体可播；签发是否产生服务端记录/凭证状态、是否逐字返回同一 URL 均未知。
