## 3. 公共签名（冻结）

同步与异步仅 `async` 差异，全部返回 `ApiResponse`：

```python
def list_subdevices(hub_serial: str, *, version: str | None = None) -> ApiResponse
def subdevice_info(subdevice_serial: str) -> ApiResponse
def channels(subdevice_serial: str) -> ApiResponse
```

**协议差异**：与 vod/inspection 等 header-token 接口不同——三者 token 位于 **form**（`accessToken` 作为表单字段），`body_encoding=form_urlencoded`，flat form；`ResponsePolicy` 为 String `"200"` `code`/`msg`/`data`（`success_values=("200",)`），非 int 200 信封。1356 发送**父** `hub_serial` 作 `deviceSerial`；1357/1358 发送**子** `subdevice_serial` 作 `deviceSerial`——序列号角色由调用方传入，SDK 不推断父子身份或通道号。

## 4. 参数与验证规则

- `hub_serial`/`subdevice_serial`：必填非空白 UTF-8 str 原样发送；来源要求存在英文字母时**大写**——SDK **拒收 ASCII 小写字母**，绝不静默大写/strip/拼接，不发明长度/正则上限。
- `version`（仅 1356）：`None` 省略全部可选参数；任何 UTF-8 str（含空串）原样发送，不做数值/SemVer 转换或空白拒收——来源仅称 String/版本号，空行为未知。
- 不注入服务端默认值；不做隐式资源发现/选择。
- `data`/`raw`/未知字段与异常身份原样保留；无响应字段强制。

## 5. 保留未知项（不猜）

适用 HUB/型号与子设备范围；响应字段 requiredness 与 null/type 差异；`version` 语义；HUB 与 A3 资源 API 的区分。

## 6. 权限与重试

- 子账号最低 `Permission=Get, Resource=dev:序列号`——这不是当前账号已有权限的证据。
- 重放：仅沿既有「at-most-one 10002 read recovery」（provider 可 refresh 时一次恢复）；无 HTTP/网络重试、无轮询。

## 7. 敏感字段脱敏

沿用既有 request redaction；`_SENSITIVE_KEYS` 追加 `consumerId`（本批 messaging 域共享）。报告不出现原始消息/headers/body/值/ID/offset/URL 与异常细节；未知错误保留现有通用分类。
