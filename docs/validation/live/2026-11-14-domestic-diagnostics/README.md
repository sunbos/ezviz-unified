# 国内单设备只读诊断

在用户授权的国内设备上追加能力集与固件版本查询。基础信息、通道、状态、能力集和版本查询均成功；存储状态和容量没有执行，公开记录明确保持not_verified。结果见[公开回执](domestic.json)。

具体设备在线状态、能力标记和升级提示仅供本次本地验收判断，不提交公开仓库。能力集声明不等于实际对讲、布防、云台等动作已验证；版本查询也没有触发升级。

本次业务请求使用method/path和区域origin白名单：即使误调用其他SDK方法，未列入的网络请求也会在转发前拒绝。没有实际设置、安全状态、存储介质或媒体变更。设备详情类通过只表示请求与基本返回结构满足预期，不推广为全硬件支持。
