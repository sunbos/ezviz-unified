# 技能包验证说明（2026-11-15）

本目录记录 `skills/` 下三个技能包的一轮验证：格式检查、7 个合成计划案例的人工语义审查，以及一次 `harness.review` 命令抽查。

## 范围与方法

- 对象：`ezviz-device-inspection`、`ezviz-contract-review`、`ezviz-doc-maintenance`。
- 案例：`evals/skills/cases.json` 中 7 个合成计划案例，场景为虚构，期望产出是计划而非实际执行。
- 判定标准：`evals/skills/expectations.json`，为人工语义审查标准，不是自动评分器。
- 模型输入：仅技能包文本、对应案例与输出格式，未提供 expectations；被测模型会话未启用工具（`tools_enabled=false`，模型 `devin/swe-2`）。
- 隔离边界：输入隔离不等于盲测。技能包作者与评审人参与了迭代式案例设计，相同案例在多轮修订中被复用，结果不构成隐藏留出基准。

## 结果

- 三个技能包格式检查完成。
- 7 个最终计划经人工核对均覆盖核心案例标准；这是人工审查结论，不是自动执行通过率。
- 空页案例中，进一步翻页仅以另行授权为前提提出建议；本次验证未执行也未批准任何枚举，线上单设备工作流保持有界。
- 早期两轮回复曾扩大仅报告范围、或基于不完整证据建议注册；技能包修订后以相同案例重跑，得到上述结论。
